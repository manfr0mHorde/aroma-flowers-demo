# Aroma Flowers · Неофициальная цветочная витрина (демо)

Адаптивная персональная концепция для магазина Aroma Flowers, Астана. Публичный сайт без серверной БД.

### Для покупателя
Каталог, фильтры, корзина, выбор филиала и доставки, дата и время, телефон покупателя и для счёта Kaspi, подготовка заявки для WhatsApp.

### Для флориста
Демонстрационный кабинет, редактирование букетов, цена, доступность, локальная статистика. Все изменения хранятся только в браузере; нет общей синхронизации.

### Безопасность демо
Сайт не официальный, товары и цены примерные. По умолчанию нельзя отправлять сообщения действующему магазину: для теста нужно явно настроить номер в кабинете. Переход в WhatsApp не равен фактической отправке или оплате. Подтверждение заказа и выставление счёта Kaspi остаются за флористом.
